# 🕯️ Premiers pas

## Dépendances

Installez **Armature**, **BetterModel**, **PacketEvents** et votre fournisseur d’items/actions dans le dossier `plugins/` du serveur. Redémarrez le serveur après la première installation. Armature se désactive si BetterModel est absent. PacketEvents est optionnel, mais certaines fonctions importantes seront indisponibles.

Placez les fichiers bbmodel dans `plugins/Armature/models/`.

## Premier contrôle de dépannage

Au démarrage et lors d’un rechargement, Armature indique les animations manquantes pour chaque modèle. Les noms manquants sont ignorés sans danger, mais l’action correspondante ne peut pas être jouée tant que l’animation n’existe pas dans l’asset BetterModel.
