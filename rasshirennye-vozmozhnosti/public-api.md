# 💻 Обзор API для разработчиков

Для запроса представления используйте `com.armaturemc.api` у плагина, владеющего геймплеем. Не требуется импортировать BetterModel или Armature. API предоставляется активным плагинами Armature. Запросы не создают разрешения на оружие, патроны, урон или геймплей.

Источники версии 2.0.0 сообщают о `API_VERSION = "2.0.0"` и `API_MAJOR_VERSION = 1`. Версия продукта и версия контракта API различаются: API сохраняет совместимость источников внутри мажорной версии контракта 1. Новые перегрузки для автономного представления требуют соответствующий API/выполняемое окружение версии 2.0.0. Они отсутствуют в опубликованном артефакте версии 1.3.0.

Начните с [Setup](public-api/setup.md), затем выберите [Animations & Presentations](public-api/animations.md), [Signals](public-api/signals.md) или [Providers](public-api/providers.md). [Examples](public-api/examples.md) содержит полный исходный код Java.

Операции игрока возвращают `CompletableFuture` и расписываются на расписании игрока. Результат подтверждает принятие или отклонение, а не визуальное завершение. Никогда не блокируйте поток игрока, ожидая будущего. Используйте события жизненного цикла анимации для конечного завершения. Распишите последующие действия геймплея на расписании игрока до обращения к состоянию Bukkit.
