# 🔗 Поддерживаемые плагины

Интеграции необязательны. Armature предоставляет предмет. Свой плагин отвечает за его идентификацию, игровой процесс и, где применимо, финальную доставку пакета ресурсов.

| Интеграция | Идентификация предмета | События/состояние | Мост пакета | Адаптер скрипта/API |
| --- | --- | --- | --- | --- |
| [ItemsAdder](itemsadder.md) | `itemsadder:namespace:id` | Идентификация. Общие предметы/триггеры ванили | Да, ItemsAdder отвечает за доставку | — |
| [Nexo](nexo.md) | `nexo:id` | Идентификация. Общие предметы/триггеры ванили | Да, Nexo отвечает за доставку | — |
| [CraftEngine](craftengine.md) | `craftengine:namespace:id` | Идентификация. Общие предметы/триггеры ванили | Да, CraftEngine отвечает за доставку | — |
| [WeaponMechanics](weaponmechanics.md) | `weaponmechanics:weapon_title` | Огонь, прицеливание, перезарядка, режим оружия/огнестрела и состояние оружия | Не является поставщиком пакета | События презентации и переопределения аксессуаров |
| [Skript](skript.md) | Использовать существующую идентичность предмета | Сигналы, отправляемые скриптом, жизненный цикл анимации | Нет | Встроенные эффекты/выражения/события |
| [MythicMobs](mythicmobs.md) | Использовать существующую идентичность предмета | Сигналы навыков, жизненный цикл анимации | Нет | Встроенные механики/триггеры |
| [Denizen](denizen.md) | Использовать существующую идентичность предмета | Сигналы скрипта, жизненный цикл анимации | Нет | Встроенные команды/события |

[PlaceholderAPI](../../nachalo-raboty/profili/variables.md) предоставляет значения для общих переменных. Он не поставляет предметы и пакеты ресурсов.

В селекторе указывайте идентификатор с пространством имён. Создавайте предметы из примеров и игровое оружие в соответствующих плагинах. После обновления провайдера проверьте идентификаторы, подключённые интеграции, журналы и итоговые ресурсы.

Для поставщиков пакетов завершите полный процесс генерации поставщика и предоставьте полученный пакет. Пересборка Armature сама по себе не гарантирует, что игрок получил обновленный ZIP-архив поставщика.
