# 🛠️ CraftEngine

Установите CraftEngine рядом с Armature и создайте кастомный предмет, идентифицированный ниже, используя собственную конфигурацию этого плагина. Пример Armature использует поставляемую модель `arm_sword`. Он не создает кастомный игровой предмет.

## Завершить профиль

```yaml
wiki_craftengine:
  match:
    item: craftengine:my_pack:wiki_sword
  model:
    name: arm_sword
    hide-vanilla-hand: true
  animations:
    movement:
      - animation: base
    actions:
      - trigger: player:attack
        animation:
          name: swing
          duration: 8t
```

Сохраните под `plugins/Armature/profiles/`, перезагрузите профили, получите этот точный предмет поставщика и проверьте соответствующий профиль. Отведите его: ожидаемый клип анимации — `swing`. Проверьте обе руки, если предмет можно держать в любой из них.

## Работа с пакетом ресурсов


Armature автоматически обнаруживает CraftEngine. Мост добавляет ресурсы Armature в рабочий процесс пакета ресурсов CraftEngine. Повторное использование валидно только тогда, когда контент Armature и входные данные поставщика все еще соответствуют успешному отчету генерации. Изменение модели, входных данных поставщика или настроек целевого пакета требует новой сборки поставщика.

Используйте рабочий процесс перезагрузки/сборки версии CraftEngine и собственную доставку пакетов. Прочитайте журнал генерации: выполнение команды без завершенной сборки не является успешным обновлением активов.


После изменения моделей Armature или активов рендерера:

```text
/armature reload pack
/ce reload all
```

Синтаксис команды поставщика может отличаться в зависимости от версии установленного поставщика. Используйте его собственную помощь для аргументов. Выберите правильную цель пакета Minecraft и примите/скачайте финальный пакет поставщика. Если в результате отсутствуют текстуры, проверьте финальный ZIP перед повторным сопоставлением предметов.

Поставщик идентифицирует предметы. Общие функции экипировки/снимания экипировки Armature и события ванилы остаются доступными. Не предполагайте, что он предоставляет события типа WeaponMechanics для стрельбы или перезарядки. Эмитируйте кастомные игровые сигналы через публичный API при необходимости.

См. [Пакеты ресурсов](../../configuration/resource-packs.md) для столкновений, фильтров, раздельной доставки и отчетов о генерации.
