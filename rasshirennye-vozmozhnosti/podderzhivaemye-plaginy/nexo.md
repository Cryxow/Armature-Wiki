# 💎 Nexo

Установите Nexo рядом с Armature и создайте кастомный предмет, идентифицированный ниже, используя собственную конфигурацию этого плагина. Пример Armature использует поставляемую модель `arm_sword`. Он не создает кастомный игровой предмет.

## Завершить профиль

```yaml
wiki_nexo:
  match:
    item: nexo:wiki_sword
  model:
    name: arm_sword
    hide-vanilla-hand: true
  animations:
    movement:
      - animation: base
    actions:
      - trigger: player:attack
        animation:
          name: swing
          duration: 8t
```

Сохранить под `plugins/Armature/profiles/`, перезагрузить профили, получить этот точный предмет-провайдера и проверить соответствующий профиль. Замахните им: ожидаемый клип анимации — `swing`. Проверьте обе руки, если предмет можно держать в любой из них.

## Работа с пакетом ресурсов


Armature автоматически обнаруживает Nexo. Мост готовит ресурсы Armature, добавляет их в пакет Nexo в течение жизненного цикла генерации, а затем завершает постгенерационные преобразования по отношению к соответствующему завершенному пакету. Готовность зависит от этого полного цикла работы, а не от директории с активами из вчерашнего дня.

Сериализация Nexo и наложения влияют на итоговые файлы. Проверьте завершённый ZIP-архив на наличие правильных определений целевой версии и пространства имен Armature. После генерации используйте собственный цикл доставки Nexo. Скопированная директория входных данных не является доставкой подключённому игроку.


После изменения моделей Armature или активов рендерера:

```text
/armature reload pack
/nexo reload pack
```

Синтаксис команды провайдера может отличаться в зависимости от версии установленного провайдера. Используйте его собственную справку для аргументов. Выберите правильную цель пакета Minecraft и примите/скачайте итоговый пакет провайдера. Если в результате отсутствуют текстуры, проверьте итоговый ZIP-архив перед повторным поиском предмета.

Провайдер определяет предметы. Общие механизмы Armature для экипировки/снятия и события из ванильного Minecraft остаются доступными. Не предполагайте, что он предоставляет события типа «выстрел» или «перезарядка» из WeaponMechanics. При необходимости отправляйте кастомные сигналы геймплея через публичный API.

См. [Пакеты ресурсов](../../configuration/resource-packs.md) для информации о коллизиях, фильтрах, раздельной доставке и генерации отчетов.
