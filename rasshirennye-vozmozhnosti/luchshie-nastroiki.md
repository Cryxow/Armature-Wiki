# 🌊 Движение и физика

Процедурное движение комбинируется с авторскими анимациями. Начинайте с встроенных по умолчанию настроек, затем изменяйте слои по одному. Настройки, подходящие для винтовки, могут быть избыточными для легких предметов.

## Колышение

`render.motion.sway` добавляет поворот взгляда и движения. Отдельные `look` и `movement` дают контроль над азимутальным углом, углом наклона и креном. Значения с знаком меняют направление реакции. `lerp-speed` управляет сглаживанием; `0.0` убирает интерполяцию взгляда. `maximum-rotation` ограничивает совокупный эффект. `affects-camera-bone` решает, достигает ли колыхание кости камеры. Индивидуальные правила движения могут переопределить `sway-rate`.

## Колышение и следование камеры

Колышение использует пройденное расстояние, `cycles-per-block`, амплитуду горизонтального/вертикального колебания и амплитуду крена. Частота и демпфирование настраивают реакцию пружины. Следование камеры использует коэффициенты поворота азимутального угла и угла наклона, максимальное смещение и компенсацию наклона. Включите слой перед настройкой его параметров. Отключенные слои не вносят вклад.

## Physics

Нативные физические кости используют пружинное движение от ускорения и поворота. `.armature` v2 использует явный свойство **Physics**. Устаревшее `.bbmodel` использует `phy_*`. Физика независима от визуальной роли и не является симуляцией столкновений. Аксессуар может переопределить настройки физики для каждого экземпляра.

| Параметр | Эффект |
| --- | --- |
| `enabled` | Активировать симуляцию для отмеченных костей |
| `acceleration-gain` | Реакция на ускорение движения |
| `maximum-angle` | Ограничение угла раскачивания |
| `frequency` | Скорость реакции |
| `damping` | Сопротивление колебаниям. Значение около 1 успокаивает без отскока |
| `turn-gain` | Дополненная реакция на поворот взгляда |

## Рецепты настройки

- **Тяжелый аксессуар:** снизьте частоту и уменьшите коэффициент поворота. Держите демпфирование около 1, если остановка вызывает отскок/резкий рывок.
- **Тихая камера:** уменьшите коэффициенты взгляда и отключите колыхание камеры перед добавлением анимации кости камеры.
- **Только покачивание при ходьбе.** Включите покачивание и отключите инерцию при повороте взгляда и следование за камерой.
- **Поиск причины смещения.** Временно отключите процедурные слои и сравните позу покоя модели. После исправления точек вращения снова включите нужные слои.

Примените эти настройки через `/armature reload config`. Пересоздавайте или скачивайте пак ресурсов только при изменении опций, влияющих на него. Протестируйте на клиенте, который будет использоваться: рендеринг с шагом сервера и опциональный клиентский рендеринг с частотой кадров могут ощущаться по-разному. [Автор физики ](../nachalo-raboty/modeli/physics.md) объясняет точки вращения.
