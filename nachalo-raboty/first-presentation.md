# 🚀 Первая анимация в игре

В руководстве используется модель `models/default/arm_sword.bbmodel` из
комплекта Armature и её клипы `base`, `swing`, `equip` и `unequip`.
Нативный движок по умолчанию поддерживает эту модель `.bbmodel`. Для
первой проверки можно взять модель из комплекта без установки расширения
Blockbench.

## 1. Назначьте предмет одному профилю

Используйте тестовый сервер или сделайте резервную копию. Профиль из
комплекта для группы мечей подходит в том числе для алмазного меча.
Переместите его файл `.yml` за пределы `profiles/`, чтобы алмазный меч
подходил только под учебный профиль.

## 2. Создайте профиль

Сохраните профиль в `plugins/Armature/profiles/wiki-sword.yml`.

```yaml
wiki_sword:
  match:
    item: minecraft:diamond_sword
  model:
    name: arm_sword
    hide-vanilla-hand: true
  animations:
    movement:
      - animation: base
    actions:
      - trigger: player:attack
        animation:
          name: swing
          cooldown: 3t
      - trigger: item:equip
        animation: equip
      - trigger: item:unequip
        animation: unequip
```

Корневой ключ `wiki_sword` — идентификатор профиля. `arm_sword` — имя
файла модели без каталога и расширения.

## 3. Загрузите профиль и передайте пакет

Выполните `/armature reload all`. Если пакетом управляет внешний
провайдер, выполните его процедуру сборки или перезагрузки и при
необходимости запустите `/armature reload providers`. Передайте игроку
итоговый пакет провайдера. Если провайдера нет, включите сборку автономного
ZIP. Размещение и доставка описаны в разделе
[Пакеты ресурсов](../configuration/resource-packs.md).

## 4. Проверьте анимации

Возьмите алмазный меч в основную руку. Для руки должен воспроизводиться
`base`, а при атаке — `swing`. Проверьте, что при выборе предмета и
переключении с него воспроизводятся соответствующие клипы. Команда
`/armature profile inspect <player>` покажет выбранный профиль, а
`/armature status` позволит проверить движок рендеринга.

Если модель не появилась, проверьте профиль, диагностику моделей и
клипов, а также загруженный пакет. Затем при необходимости правьте
трансформации. См. [Устранение неполадок](../ustranenie-nepoladok.md).

После проверки удалите учебный профиль, верните исходный и выполните
перезагрузку. Далее см. [Создание первой модели](model-blockbench.md)
или [Правила движения](profili/movement.md).
