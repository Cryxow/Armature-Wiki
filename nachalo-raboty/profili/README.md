# 🗂️ Структура профилей

Профили — это файлы YAML, расположенные ниже `plugins/Armature/profiles/**/*.yml`. Каждый корневой ключ представляет собой глобально уникальный идентификатор профиля. Имена файлов или папок не ограничивают область видимости ссылок. Современные и устаревшие файлы могут сосуществовать, но для новых профилей используйте современный формат.

## Минимальный профиль предмета

```yaml
wiki_stick:
  match:
    item: minecraft:stick
  model:
    name: wiki_player
```

Модель `wiki_player` должна существовать. Статический профиль может не содержать анимаций. Добавление правил выбирает авторские клипы, а не определяет новую геометрию модели.

## Полная форма

```yaml
wiki_rifle:
  match:
    item: weaponmechanics:m4a1
    when: variable.rifle-enabled == true
  model:
    name: arm_rifle
    offset: 0.0
    sway-rate: 1.0
    hide-vanilla-hand: true
  animations:
    movement:
      - animation: base
    actions:
      - trigger: weaponmechanics:fire
        animation:
          name: fire
          cooldown: 3t
    additives:
      - when: player.falling == true
        animation: fall
        playback: loop
        weight: 0.5
```

Укажите `rifle-enabled` в [variables.yml](variables.md) и предоставьте все модели клипа, использованные выше. Имена-заглушки для активов не являются встроенными возможностями.

## Поля и представление

| Поле | Обязательно | Значение |
| --- | --- | --- |
| `<profile-id>` | да | Корневой ID: строчные буквы, цифры, `.`, `_` или `-`. |
| `match` | да | Точные ID предметов, групп предметов, шаблонов или структурированный выборщик. |
| `model.name` | да | ID загруженной модели для активного рендерера. |
| `model.offset` | нет | Вертикальное смещение в пространстве модели. По умолчанию `0.0`. |
| `model.sway-rate` | нет | Множитель качения профиля. По умолчанию `1.0`. |
| `model.hide-vanilla-hand` | нет | Скрывает оригинальный предмет от первого лица. По умолчанию `true`. |
| `model.render-events` | нет | Опциональный список разрешенных событий рендеринга для условных сессий. |
| `model.held-item` | нет | Визуальное состояние копии предмета в руке: `static`, `source` или `rules`. Отсутствие значения сохраняет существующее поведение. |
| `animations.movement[].hide-vanilla-hand` | нет | Переопределяет значение модели, пока выбрано это правило движения. |
| `animations.actions[].hide-vanilla-hand` | нет | Переопределяет значение движения/модели, пока активна эта действие. |
| `type` | нет | `item` (по умолчанию) или переразрушаемый `attachment`. См. [комбинированные профили](attachments.md). |
| `animations` | нет | Содержит `movement`, `actions` и/или `additives`. |
| `integrations` | нет | Настройки представления, принадлежащие поставщику. |

`model.offset` перемещает корень модели в пространстве модели. `sway-rate` масштабирует качение взгляда/движения без изменения боба или слежения камерой.

`hide-vanilla-hand` отвечает только за презентацию. Armature использует настроенную маску клиента/путь к пакету ресурсов. Предмет инвентаря сервера никогда не заменяется. Пустую руку можно выбрать с помощью `match.item: minecraft:air`.

`match.when` блокирует активацию; [варианты](variants.md) выбирают условную презентацию в активном профиле, а [аксессуары](attachments.md) монтируют переразмерные экземпляры моделей. Переменные YAML должны находиться исключительно в `variables.yml`. Презентации, созданные через API, имеют свой собственный явный контракт по inline-переменным.

## Безопасная загрузка

Запустите `/armature reload profiles`, проверьте предупреждения и используйте `/armature profile inspect <player>`. Неправильный файл не восстанавливается при перезагрузке. Ошибки ссылок, такие как неизвестные профили аксессуаров, циклы, неизвестные переменные или невалидные условия выбора, отклоняют кандидатскую библиотеку. Активная библиотека остаётся на месте. Валидация моделей/клипов/монтирования также охватывает неактивные варианты.

Новые ссылки на модели требуют генерации и доставки модели/пакета, а не просто перезагрузки профиля. См. [Полные примеры](examples.md) и [Обновление](../upgrading.md).
