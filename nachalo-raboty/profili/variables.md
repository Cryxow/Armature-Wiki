# 🔤 Общие переменные и PlaceholderAPI

Только `plugins/Armature/variables.yml` объявляет переменные YAML:

```yaml
variables:
  weapon-skin:
    type: string
    source: placeholderapi
    placeholder: "%myplugin_weapon_skin%"
    refresh: 10t
    default: classic
  charm-unlocked:
    type: boolean
    source: placeholderapi
    placeholder: "%myplugin_charm_unlocked%"
    refresh: 10t
    default: false
  player-level:
    type: number
    source: placeholderapi
    placeholder: "%player_level%"
    refresh: 10t
    default: 0
```

Имена плейсхолдеров выше — примеры, а не встроенные расширения. Константы, источники провайдеров/API и `number`, `boolean`, `string`, `duration`, `enum` сохраняют существующую синтаксическую структуру. Используйте `variable.<id>` в любом профиле без импортов. `placeholder.<id>` остаётся алиасом. Целые числа используют `number`.

Определения общие, значения нет: кэши принадлежат игроку и руке/сессии. Установленные модели разделяют разрешение переменных у владеющей руки. Разрешаются только ссылающиеся определения. Значения провайдеров/API используют текущий контекст, включая текущие аргументы события. Данные события не пересылаются как значение переменной для последующего события. Пропущенные/неконвертируемые внешние значения используют объявленный дефолт, затем нейтральное значение типа. Пропущенный файл — это пустая регистрация.

Локальные объявления YAML отклоняются, включая внутри вариантов и экземпляров. Перенесите старые объявления в общий файл вручную, разрешите конфликтующие ID и удалите локальные блоки. Общие объявления остаются в собственности администратора. Самостоятельные запросы Java `ArmaturePresentation` сохраняют существующий контракт встроенных переменных.

## Источники и типы

| Источник | Объявление/использование |
| --- | --- |
| `constant` | `value` предоставляет фиксированное типизированное значение |
| `placeholderapi` | `placeholder` разрешается через установленные PlaceholderAPI/расширения |
| `provider` | Провайдер/путь идентифицирует значение именного провайдера |
| `api` | Путь читает текущий контекст API/сигнала |

Типы — это `number`, `boolean`, `string`, `duration`, `enum`. Используйте `number` для целых чисел тоже. `clamp` применяется к значениям чисел/длительности. Длительности принимают тики, секунды или числовые тики. Плейсхолдеры здесь — примеры, не расширения, встроенные в Armature.

## Ссылка на объявление

| Поле | Обязательно/по умолчанию | Значение |
| --- | --- | --- |
| `type` | Обязательно | `number`, `boolean`, `string`, `duration`, `enum` |
| `source` | `constant` | Один источник из таблицы выше |
| `value` | Обязательно для константы | Фиксированное числовое значение. Запрещено для других источников |
| `placeholder` | Обязательно для PlaceholderAPI | Строка-заглушка, включая `%`. Запрещено для других источников |
| `provider` | Обязательно для провайдера. Опционально для API | Пространство имен для поиска. Запрещено для других источников |
| `path` | ID переменной при опускании | Текущее поле контекста для источников провайдера/API |
| `refresh` | `1t`, не менее 1 тика | Длительность обновления заглушки. Значения провайдера/API читают текущий контекст |
| `default` | Нейтральное значение типа | Типовая заглушка при ошибке поиска/конвертации |
| `clamp` | Опущено | Конечный упорядоченный `[minimum, maximum]`, только число/длительность |

`enum` — это строковый тип, а не отдельно объявленный `values` список. Константные и значения по умолчанию числового и булевого типов должны использовать соответствующие типы YAML.

```yaml
variables:
  rounds:
    type: number
    source: provider
    provider: weaponmechanics
    path: ammo
    default: 0
  input-allowed:
    type: boolean
    source: api
    path: allowed
    default: false
  mode:
    type: enum
    source: constant
    value: semi
  animation-time:
    type: duration
    source: constant
    value: 12t
    clamp: [0, 40]
```

## Пример полной константы

Сохраните это как `plugins/Armature/variables.yml`:

```yaml
variables:
  rifle-enabled:
    type: boolean
    source: constant
    value: true
    default: false
  weapon-skin:
    type: string
    source: constant
    value: classic
    default: classic
  player-level:
    type: number
    source: constant
    value: 10
    default: 0
```

Используйте `variable.rifle-enabled == true` или `variable.player-level >= 10` из любого профиля без импорта. Перезагрузите профили после изменения реестра, затем проверьте выбранную презентацию игрока.

Отсутствующие или неконвертируемые внешние значения используют `default`, затем нейтральное значение типа. Данные события используют текущее событие и не сохраняются для последующего события. Изменение переменной выбора не вызывает пересборку пакета: все ссыляющиеся модели должны прошли валидацию и уже присутствовать в опубликованных активах.
