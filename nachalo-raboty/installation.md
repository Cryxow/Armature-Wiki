# 📥 Установка и требования

## Требования

| Компонент | Требование |
| --- | --- |
| Сервер | Paper или Folia с API Paper 1.21.8 или новее. Перед установкой проверьте целевую версию. |
| Java на сервере | Java 25 |
| PacketEvents | Обязательный плагин. Для компиляции и выполнения интеграция рассчитана на версию 2.13.0. |
| BetterModel | Требуется только при `render.backend: bettermodel`. Интеграция совместимости рассчитана на версию 3.4.1. |
| Пакет ресурсов | Игроки должны принять итоговый пакет с ресурсами, созданными Armature. |
| Клиентский мод | Необязательный. Сборки Fabric предназначены для конкретных версий от 1.21.8 до 26.2. См. [таблицу совместимости](../klientskii-mod/installation.md). |

Диапазон версий оверлеев пакета не меняет требования к API сервера и
список версий Minecraft, которые поддерживает мод Fabric.

## Установка

1. Остановите сервер. Поместите дистрибутив `Armature-2.0.0.jar` и
   PacketEvents в `plugins/`. Файлы `-plain` и отдельный JAR API
   предназначены для других задач.
2. До запуска установите плагины, которые предоставляют предметы или
   события для ваших профилей. Установите BetterModel, если выбрали этот
   движок рендеринга.
3. Запустите сервер с Java 25. По умолчанию используется движок `native`.
4. Выполните `/armature diagnostics startup` и `/armature status`.
   Устраните ошибки загрузки перед проверкой профилей.
5. Соберите и передайте пакет ресурсов через выбранного провайдера или
   разместите автономный ZIP на хостинге. Убедитесь, что клиент получил
   пакет. См. [пакеты ресурсов](../configuration/resource-packs.md).
6. Подключитесь из клиента Minecraft, примите пакет и запустите
   [первую анимацию в игре](first-presentation.md).

## Создаваемые файлы

```text
plugins/Armature/
  config.yml
  messages.yml
  variables.yml
  models/
  profiles/
  armors/
  resource_pack/
```

При первой установке Armature копирует встроенные файлы из `default-assets/`
и сохраняет файлы администратора. Обновления могут добавлять новые файлы по
умолчанию. Чтобы посмотреть, какие файлы будут заменены, выполните
`/armature config restore-defaults`. Повторите команду с `--confirm`,
только если хотите восстановить эти файлы.

В каталоге `internal/` хранятся автоматически созданные кэши и снимки
данных провайдеров. Создание `resource_pack.zip` и `renderer_pack.zip`
зависит от настроек пакета.

## Обновления и загрузка

Используйте свой канал распространения Armature для загрузки плагина и
совместимых версий клиентского мода и расширения Blockbench. Сохраните
предыдущий JAR и настройки администратора до проверки новой комбинации.
Артефакт API предназначен для компиляции ваших интеграций.
