# 🎛️ Редактор костей в игре

Редактор изменяет смещения представления без редактирования вашего исходной модели или профиля. Удерживайте предмет с активным профилем и выполните `/armature editor` с разрешением `armature.command.editor`.

```text
/armature editor open
/armature editor close [--confirm]
/armature editor reset [item|profile] [--confirm]
/armature editor export [item|profile]
/armature editor undo
/armature editor redo
/armature editor set <bone> <pos|rot> <x> <y> <z>
/armature editor diff [item|profile]
/armature editor mirror <left|right>
```

Без `/armature editor` — это сокращение для `editor open`. Редактору требуется, чтобы игрок держал предмет с активным профилем Armature и редактируемыми костями модели. Его диалог содержит ползунки и видимое состояние `temporary preview`. `editor set` позволяет вводить точные числовые значения (пиксели или градусы) в случае, если клиент не поддерживает ввод текста в диалоге.

`undo` и `redo` сохраняют ограниченную историю сессий (50 изменений). `diff` выводит базовую авторскую модель, несохраненные `temporary preview` и сохраненные `item-override` или `profile-override`. `mirror left` копирует соответствующие значения справа в кости слева; `mirror right` делает обратное и зеркально отражает знаки позиции и вращения по оси X.

`reset` выводит разрушительный превью `item-override`/`profile-override` и требует `--confirm`. Он удаляет сохраненные значения для этого диапазона и обновляет живое представление. `close` блокирует процесс, пока `temporary preview` не станет чистым. Повторите его с `--confirm`, чтобы отбросить эти несохраненные значения. `export` генерирует фрагмент YAML, готовый к профилю, для `editor-overrides.yml`, включает сводку несохраненных данных и никогда не пишет конфигурацию исходного профиля.

Все три слоя значений явно указаны в сообщениях редактора: `temporary preview` — живые и несохраненные данные, `item-override` — сохраненные для одного предмета/профиля, и `profile-override` — сохраненные для каждого предмета, решенного этим профилем. Сохранение переопределения или применение превью изменяют только представление. Файлы исходного профиля никогда не мутируются редактором.

Разрешение: `armature.command.editor`.

## Сохраненные переопределения

Операторы с `armature.command.editor` могут запускать `/armature editor`, держа предмет, назначенный профилю. Диалоговое окно выбирает редактируемую кость модели и показывает ползунки позиции и вращения. Применение изменений обновляет всех онлайн-игроков, использующих этот же предмет или область действия профиля.

Переопределения сохраняются отдельно в `plugins/Armature/editor-overrides.yml`:

```yaml
version: 2
profiles:
  m4a1:
    bones:
      root:
        position: [0.0, 1.0, 0.0]
        rotation: [0.0, 2.0, 0.0]
items:
  m4a1:
    weaponmechanics:m4a1:
      bones:
        root:
          position: [0.0, 2.0, 0.0]
          rotation: [0.0, 0.0, 0.0]
```

Значения профиля наследуются первыми, значения предмета их перекрывают, а несохраненные живые значения имеют наивысший приоритет. `Save item` влияет только на предмет в руке; `Save profile` влияет на все предметы, разрешенные профилю. Эти исправления меняют только представление и не изменяют игровой процесс или состояние инвентаря. Значения позиции используют единицы модели Blockbench (пиксели) и конвертируются в блоки пространства модели с `/16`. Значения вращения используют градусы в обычном диапазоне `-180..180`.

## Проверить исправление

Используйте `editor diff` перед сохранением. Сохраните для области действия предмета для одного идентификатора или для области действия профиля для каждого совпадающего предмета, затем откройте редактор заново и подтвердите сохранение. Протестируйте обе руки, надевание/снятие и всех игроков, использующих эту область действия. Экспорт — это фрагмент YAML для файла переопределения, а не сохраненный проект `.armature`.
