# 💾 Сохранение и установка моделей

## Сохранить исходник

Использовать **File → Save / Save As** или обычную комбинацию клавиш. Отдельной панели экспорта/сохранения в Armature нет. При сохранении с инкрементом открывается Сохранить как. Перезагрузите файл и проверьте геометрию, иерархию, анимации, роли и значения физики.

Документ должен идентифицировать `meta.model_format: armature_fpv`, `armature.renderer: native` и `armature.format_version: 2`. Версия формата модели независима от версии релиза плагина `2.0.0`. Сохраните исходный редактируемый файл в системе контроля версий или в резервной копии ваших активов.

## Установить на сервер

Скопируйте `my_rifle.armature` в `plugins/Armature/models/` или подкаталог. Ссылку на `model.name: my_rifle` укажите в профиле. ID моделей выводятся из названий файлов без расширения. Сохраняйте их уникальными даже в разных подкаталогах. Совместимые активы `.bbmodel` могут находиться рядом с активами версии 2 под нативным движком рендеринга.

Использовать `/armature reload models` для изменений исходника. Если изменились клипы или кости, на которые ссылается профиль, перезагрузите профили; `/armature reload all` применяет полный кандидат Armature.

## Сгенерировать и передать

Пересоберите пакет Armature, запустите полный цикл генерации вашего провайдера и заставьте игрока скачать финальный пакет. Дополнительные клиентские сборки и активы серверного рендерера имеют разные пути передачи. Тестируйте с и без клиентской модификации. См. [Пакеты ресурсов](../../configuration/resource-packs.md).

## Общие ошибки валидации

| Диагностика | Исправление |
| --- | --- |
| Неподдерживаемая версия .armature | Пересоздайте v1 как v2. Не просто переименовывайте или редактируйте заголовок |
| Неизвестная роль/не булева физика | Присвойте поддерживаемую роль и используйте булево значение физики |
| Несколько ролей камеры | Сохраните единственную роль камеры для выполнения |
| Отсутствующий клип или кость крепления | Обновите профиль/референс или добавьте авторизованный актив |
| Дублирование идентификаторов модели/клипа | Выберите уникальные идентификаторы |
| Зарезервированное имя узла `__armature_` | Переименуйте авторизованный узел |

Проверки валидации библиотеки включают неактивные варианты и переопределения аксессуаров. Исправьте весь кандидат. Ветка, которая сейчас невидима, все равно должна иметь валидные активы. Сохраните последнюю известную рабочую сборку до загрузки новой ревизии и её визуальной проверки.
