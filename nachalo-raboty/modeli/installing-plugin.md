# 🔌 Установка расширения Armature для Blockbench

Используйте **Blockbench Desktop 5.0+**, официальный плагин **Cameras** и
версию расширения Armature, совместимую с форматом вашей модели.
Расширение служит для создания моделей. Серверный плагин Minecraft и
клиентский мод устанавливаются отдельно.

## Установка из файла

1. Возьмите `armature_blockbench.js` из дистрибутива Armature Blockbench,
   который поставляется с вашими инструментами.
2. Откройте **Plugins → Load Plugin from File** и выберите файл JavaScript.
3. Оставьте официальный плагин **Cameras** включённым для предпросмотра
   в редакторе.
4. Проверьте, что при создании проекта доступен **Armature FPV Model**.
   В проекте этого формата должно появиться меню **Armature**.

При сборке из исходников команда `npm run verify` создаёт
`dist/armature_blockbench.js` и стандартный скелет v2. Готовый файл из
дистрибутива можно установить сразу.

## Проверка установки

[Создайте первую модель](../model-blockbench.md). Щёлкните кость правой
кнопкой мыши и убедитесь, что доступны **Armature → Assign Role** и
**Physics**. При сохранении создаётся файл `.armature` формата v2. Если
меню отсутствует, перед переустановкой проверьте формат проекта.

На снимках показаны инструменты веб-версии Blockbench. Для установки из
файла, сохранения и повторного открытия модели используйте Blockbench Desktop.
