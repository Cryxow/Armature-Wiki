# 📲 Установка и совместимость

Мод Fabric **необязателен**. Для игроков без мода работает нативный движок
сервера. Используйте клиентский JAR именно для своей версии Minecraft.
В таблице приведены целевые версии отдельных сборок. Перед использованием
проверьте совместимость итоговых версий сервера 2.0.0 и клиентского мода.

## Установка

1. Установите **Fabric Loader 0.19.5 или новее** с версией Java из таблицы.
2. Установите [Fabric API](https://modrinth.com/mod/fabric-api) для этой
   версии Minecraft.
3. Загрузите подходящий JAR со [страницы выпусков Armature Client](https://github.com/Cryxow/ArmatureClientMod/releases).
   Поместите в каталог `mods/` экземпляра игры один JAR Armature Client.
4. При необходимости установите [Mod Menu](https://modrinth.com/mod/modmenu)
   версии из таблицы.
5. Подключитесь к серверу Armature с нативным движком и параметром
   `render.client-mod.enabled: true`. Примите обязательный общий пакет ресурсов.

Соответствующие исходные сборки сервера и клиента используют протокол **9**.
Это версия протокола обмена данными. Версии плагина и формата `.armature`
нумеруются отдельно. При смене клиентской сборки проверьте её протокол.

## Проверка рендеринга

Возьмите меч из первого учебного примера. Выключите и снова включите
клиентский рендеринг в настройках мода. Если началась перезагрузка ресурсов,
дождитесь её завершения. Проверьте, что оба движка показывают один и тот
же предмет, состояние анимации и скин. Повторите проверку после повторного
подключения с пустым кэшем моделей клиента. Готовность клиента можно
посмотреть в диагностике сервера.

Мод остаётся предварительной версией до проверки сочетаний в игре.
Эти сборки Fabric рассчитаны на версии из таблицы. Снапшоты и NeoForge
не поддерживаются. Совместимость клиента не подтверждает совместимость
сервера Paper или Folia с каждой указанной версией Minecraft.
