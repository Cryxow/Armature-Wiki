# 🎚️ Настройки и известные ограничения

В Mod Menu откройте **Mods → Armature Client → Configure**. В настройках
есть переключатель клиентского рендеринга. Без Mod Menu закройте
Minecraft и измените следующий файл.

```json
{
  "renderingEnabled": true
}
```

Путь к файлу — `config/armature-client.json`. По умолчанию используется
`true`. При изменении настройки запрашивается смена движка. Проверьте
результат после завершения перезагрузки ресурсов. Настройки камеры и
профилей задаются на сервере.

## Ограничения совместимости

| Возможность | Текущее ограничение |
| --- | --- |
| Модели | Строгий формат `.armature` v2 и совместимые модели `.bbmodel`. Формат v1 требует ручного преобразования. |
| Скины и броня | Скины, экипировка и отделка брони зависят от адаптера рендеринга и ресурсов целевой версии. |
| Предметы в руках | Состояние предметов обновляется динамически. Может понадобиться общий пакет провайдера. |
| Камера и движение | Сервер задаёт камеру, процедурные движения и физику. Сравните оба режима в игре. |
| Составные модели | Сцены с аксессуарами отрисовываются на сервере. |
| Sodium и Iris | Проверяйте нужные сочетания в игре. Компиляция не подтверждает совместимость пакетов шейдеров. |
| Fabulous и шейдеры | Маскирование шейдерами на сервере и отрисовка модом работают по-разному. Проверяйте конкретный режим графики. |

Sodium не поддерживает стандартный шейдерный режим сохранения поля зрения.
При использовании Iris проверьте свой пакет шейдеров. См.
[Рендеринг и камера](../configuration/rendering-camera.md).

При сообщении об ошибке укажите точные версии Minecraft, Java, Fabric Loader,
Fabric API, клиентского JAR, серверного плагина, Sodium, Iris и пакета шейдеров.
Приложите клиентский `latest.log`, диагностику сервера, минимальные модель
и профиль. Укажите, меняется ли симптом после перехода на серверный рендеринг.
