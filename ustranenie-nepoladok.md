# 🩺 Устранение неполадок

Начните с минимального профиля и известной загруженной модели. Сохраните точную модель, профиль, версии сервера/клиента и финальный пакет ресурсов, которые воспроизводят проблему. Изменяйте одну переменную за раз.

| Симптом | Проверьте сначала | Следующий шаг |
| --- | --- | --- |
| Нет демонстрации | Время выполнения/включено игроком, идентичность предмета, выбранный профиль, загруженная модель, принятый пакет | Инспекция профиля, инспекция модели, диагностика |
| Отсутствующая/розовая текстура | Финальный ZIP-архив поставщика, определение пространства имен/пути и целевого пакета | [Пакеты ресурсов](configuration/resource-packs.md) |
| Неправильная анимация | Точное имя клипа (регистрозависимое), условие правила/триггер, защищенное действие и время охлаждения | [Правила действий](nachalo-raboty/profili/actions.md) |
| Неправильное движение | Самоспецифичное совпадающее правило, порядок объявления связей, активы цикла/начала/конца | [Правила движения](nachalo-raboty/profili/movement.md) |
| Предмет/рука смещены | Назначение роли, поворотные точки, зеркальный клип руки, сохраненное перекрывание кости | [Роли костей](nachalo-raboty/modeli/bone-roles.md), [редактор](nachalo-raboty/in-game-editor.md) |
| Модель исчезает внутри блоков | Защита от клиппинга и точный путь шейдера/графики | [Рендеринг и камера](configuration/rendering-camera.md) |
| Отсутствует вращение камеры | Роль камеры/элемента, включенное вращение камеры и поддерживаемая графика клиента | Рендеринг и Камера |
| Неправильная кожа/броня | Классическая/узкая роль, экипировка игрока, маппинг брони и путь к текстуре | [Скины и пользовательская броня](rasshirennye-vozmozhnosti/polzovatelskaya-bronya.md) |
| Отсутствует аксессуар | Нативный движок рендеринга, ID кости/кости, к которой прикреплен аксессуар, условие, глубина и лимит сущностей | [Аксессуары](nachalo-raboty/profili/attachments.md) |
| Рендерер меняет поведение unexpectedly | Предпочтения клиента/готовность, переход на резервный режим, ожидание перезагрузки пакета ресурсов | [Клиентский рендеринг и переход на серверный](klientskii-mod/rendering-fallback.md) |
| `.armature`: отклонено | Строгий v2, обычное сохранение плагина, дубликаты/невалидные роли, диагностика экспортера | [Сохранение и развертывание ](nachalo-raboty/modeli/saving-deploying.md) |

## Краткая воспроизводимая проверка

1. Запустите `/armature diagnostics doctor`. Исправьте ошибки перед настройкой косметики.
2. Проверьте конфигурацию без применения: `/armature config validate`.
3. Проверьте предмет в руке/профиль и модель с помощью команд из [Диагностика](ustranenie-nepoladok/diagnostics.md).
4. Пересоберите ресурсы Armature/поставщика и примите финальный пакет поставщика.
5. Протестируйте после полного перезапуска сервера, если это требуется. Bukkit `/reload` не гарантирует чистый запуск или изменение движка рендеринга/зависимостей.
6. Проведите повторную проверку с отключенным клиентским рендерингом. Запишите, какой путь не работает.

Не исправляйте сбой пакета заменой уже корректного мэтчера предметов. Не удаляйте защищенное действие только для маскировки утраты сигнала перезагрузки/окончания. Найдите первый неверный шаг в цепочке: идентичность предмета → выбор → модель → пакет → рендеринг.
