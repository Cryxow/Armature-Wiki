# 📘 Introduction

Armature est un moteur d’animation des bras en vue à la première personne pour Paper. Il affiche un rig à partir de profils d’items, choisit les animations parmi des actions vanilla ou de fournisseurs personnalisés, et ajoute des mouvements optionnels de caméra, de déplacement et de balancement.

Armature contrôle uniquement la présentation. Les dégâts, munitions, projectiles et l’autorité sur l’inventaire restent gérés par le plugin de gameplay compatible.

## Ce dont Armature a besoin

* Serveur Paper, de `1.21.4` à la dernière version.
* [BetterModel](https://modrinth.com/plugin/bettermodel), requis pour le rendu des rigs.
* [PacketEvents](https://modrinth.com/plugin/packetevents), requis pour masquer la main vanilla en vue à la première personne et pour les optimisations.
* Fournisseurs optionnels : [WeaponMechanics](https://www.spigotmc.org/resources/weaponmechanics-guns-in-minecraft.99913/), [QualityArmory](https://www.spigotmc.org/resources/quality-armory.47561/), [CraftEngine](https://modrinth.com/plugin/craftengine) ou tout plugin d’items pris en charge par Armature.
